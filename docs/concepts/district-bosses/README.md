# Project CHOIR District Boss Concept Art

These five **2560×1440** concept plates were regenerated with **GPT Image 2** on 2026-08-26 after `docs/PROJECT_CHOIR_STORY_PROPOSAL.md` became the authoritative narrative direction. Each plate uses the current PROTOS provisional art, its district’s authored facade, and relevant Project CHOIR story concepts as visual references.

The shared visual language uses **hollow cyan** for safe memory or information, **striped amber** for commitment, **solid crimson or magenta** for imminent damage, and **white** for actionable weak points. Human forms remain intact and contained behind glass or synthetic membrane. Horror is clinical, tragic, and engineered rather than gory or fantastical.

These plates are **proposal and art-direction assets only**. They must never enter the Godot Web PCK. Runtime production art should use trimmed multipart atlases, shared effects, no duplicated orientation frames, and the package allocation in `docs/DISTRICT_BOSS_IMPLEMENTATION_PLAN.md`.
