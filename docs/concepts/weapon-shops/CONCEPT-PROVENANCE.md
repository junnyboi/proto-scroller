# Weapon Shop Concept Provenance

All five concepts were generated for Proto Scroller on 2026-08-26 using **GPT Image 2** through the Manus built-in image-generation connector. They are original project assets generated as design references for the implemented Godot overlay.

The shared direction requested a premium 2D game UI concept sheet at 2560×1440 with a dark industrial retro-futurist command-deck style, cream condensed headings, cyan and amber accents, subtle scanlines, exactly three product cards, Rampage Score as the visible currency, an explicit warning that spending reduces final score, and a Continue action. No external game logos, watermarks, characters, or copyrighted UI were requested.

District-specific prompt extensions were:

- **Business / Black Ledger Exchange:** repossessed Art-Deco bank vault, charcoal concrete, black transaction glass, cyan ledger lines, oxidized copper pipes, amber service lamps, and secured financial-instrument cards.
- **Residential / Ashwater Mutual Garage:** flooded neighborhood repair co-op, patched teal equipment, hanging chains, water stains, warm clinic lamps, improvised municipal machinery, and handwritten service marks.
- **Entertainment / Afterglow Mod Parlor:** casino prize counter crossed with a backstage weapons laboratory, magenta neon marquees, cyan energized glass, scorched velvet, glossy black frames, and theatrical danger.
- **Military / Iron Corridor Field Armory:** commandeered field armory beneath a siege gantry, olive-gray blast concrete, yellow hazard stripes, crane rails, red requisition stamps, and hard work lights.
- **Royal / Crownward Reliquary:** looted sovereign reliquary, black marble, tarnished gold, crimson velvet, cathedral machinery, sunburst seals, and forbidden prototype modules displayed as crown jewels.

The generated images are design targets rather than runtime textures. The game reproduces their hierarchy, palette, card geometry, and district differentiation with responsive Godot UI primitives to preserve Web export size and mobile adaptability.
